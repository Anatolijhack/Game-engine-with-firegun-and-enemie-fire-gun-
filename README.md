# Gamedev 2D

Аркадный 2D-шутер на C++ и SFML с собственным движком на основе ECS.
Вид сверху, бесконечные волны врагов, боссы, разное оружие и улучшения между волнами.

> Статус: играбельный прототип. Графика из цветных прямоугольников, звука нет.

## Игровой процесс

Вы управляете зелёным квадратом и отбиваетесь от волн врагов. Когда волна зачищена,
игра переключается на экран выбора улучшения: две случайные карточки, берёте одну.
Затем приходит следующая волна, и карта перестраивается. Каждая пятая волна с боссом.
Игра заканчивается, когда у вас кончается здоровье. Цель: продержаться дольше и набрать больше очков.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | движение |
| Мышь | прицел |
| Левая кнопка мыши / Пробел | стрельба |
| 1 – 5 | смена оружия |
| R | рестарт после смерти |
| 1 / 2 | выбор карточки в меню улучшений |

## Оружие

| Клавиша | Оружие | Как работает |
|---|---|---|
| 1 | Пистолет | одна пуля, быстрая перезарядка |
| 2 | Дробовик | веер из 5 пуль |
| 3 | Лазер | мгновенный луч, бьёт первого врага на линии (2 урона) |
| 4 | Базука | медленная ракета, взрыв в радиусе, ранит и вас |
| 5 | Огнемёт | конус перед вами, урон тиками, пока зажата кнопка |

У каждого оружия своя перезарядка. Улучшение скорострельности хранится отдельным
множителем и действует на любое оружие.

## Враги

| Вид | Появляется | Особенности |
|---|---|---|
| Grunt (красный) | всегда | идёт к игроку, стреляет |
| Fast (оранжевый) | с 3-й волны | в 1,8 раза быстрее, на 1 HP слабее |
| Tank (тёмно-красный) | с 5-й волны | медленный, на 2 HP больше |
| Rocketeer (фиолетовый) | с 4-й волны | останавливается на дистанции, стреляет ракетами |
| Flamer (жёлто-оливковый) | с 4-й волны | подбегает вплотную и поджигает |
| Boss | каждая 5-я волна | крупный, две фазы по здоровью, веер пуль и ракеты |

Босс на второй фазе (здоровье не больше половины) становится быстрее, стреляет чаще
и добавляет ракеты. Смена цвета показывает, что фаза началась.

## Волны и очки

- Число врагов: `3 + 2 * волна`, не больше 20 (на волне с боссом свита меньше).
- Здоровье врагов растёт на 1 каждые 3 волны (максимум 6 для базового врага).
- В начале каждой новой волны вы лечитесь на 1 HP.
- Стены на карте перестраиваются случайно на каждой волне.
- Очки: 10 за врага, 100 за босса.

## Улучшения между волнами

Max HP +1, лечение +2, скорострельность +20%, скорость движения +15%
и выдача оружия (дробовик, лазер, базука, огнёмёт).

## Сборка

Требования:

- компилятор с поддержкой C++17 (проект собирался в Visual Studio 2022, x64)
- SFML 3.x (используется API SFML 3: `pollEvent` возвращает `std::optional`, `sf::Vector2f` в `setPosition`)

Шрифт для текста интерфейса ищется автоматически (Arial в Windows и macOS, DejaVu в Linux).
Если шрифта нет, положите `font.ttf` рядом с исполняемым файлом. Без шрифта игра работает,
но счёт и волна показываются только в заголовке окна.

## Архитектура

**ECS.** Сущность это `{index, generation}`. Поколение растёт при удалении, поэтому
старая ссылка на удалённую сущность считается мёртвой, даже если номер переиспользован.
Компоненты лежат в `SparseSet<T>`, то есть в плотных массивах, обход идёт без хеш-поиска.
Роль сущности определяется набором компонентов: ракета это `Position + Velocity + Bullet + Explosive`,
босс это `Position + Velocity + Enemy + Health + Collider + BossAI`.

**Системы.** Каждый кадр `ModuleRegistry` вызывает системы по порядку. После каждой
применяется буфер команд (создание сущностей) и удаляются помеченные сущности, поэтому
следующая система видит согласованный мир. Порядок кадра:

```
Input → Enemy → Boss → Move → Collision → ContactDamage → Bounds →
WallCollision → BulletWall → Beam → Explosion → Flame → Wave → Render
```

**Потоки.** `MoveSystem` и поиск попаданий в `CollisionSystem` выполняются параллельно
через `ThreadPool`. Правила:

- создавать и удалять сущности можно только из главного потока (или через `CommandBuffer`);
- параллельные задачи пишут только в «свои» сущности или в свои буферы результатов;
- удаление из любого места делается через `destroyLater`, оно потокобезопасно.

**Сцены.** `SceneManager` крутит главный цикл. Сцена может запросить переключение,
вернув индекс из `WantsSwitchTo()`. `GameScene` уходит в `WaveClearScene`, когда волна зачищена,
а `WaveClearScene` возвращает в игру после выбора улучшения. Мир создаётся один раз,
при возврате состояние сохраняется.

## Как добавить своё

**Новый вид врага.** Добавьте значение в `EnemyKind`, множитель скорости в `EnemySystem::speedMul`,
условия появления в `WaveSystem::randomKind`, цвет в `RenderSystem`.

**Новое оружие.** Значение в `WeaponType`, базовая перезарядка в `baseCooldown`, ветка в
`InputSystem::Update` и метод выстрела, клавиша в `InputState` и `main.cpp`,
запись в `UpgradeKind`, `upgradeName`, `applyUpgrade` и пул в `WaveClearScene`.

**Новый компонент.** Просто структура в `Components.h`. Регистрировать ничего не нужно.

**Новая система.** Класс-наследник `System`, добавить `push_module` в конструктор
`GameScene` в нужном месте порядка.

## Известные ограничения

- Лазер и огнёмёт бьют сквозь стены, обычные пули и ракеты стены останавливают.
- Враги идут к игроку по прямой, поиска пути нет, за длинной стеной они могут застрять.
- Нет фиксированного шага симуляции: скорость игры зависит от частоты кадров
  (длительность кадра ограничена 0,1 с).
- Клавиши опрашиваются как «зажата», а не «нажата». Удержанная клавиша 1 или 2
  может мгновенно выбрать карточку при открытии меню улучшений.
- Таймер перезарядки общий для всех видов оружия: можно чередовать оружие, обходя долгую перезарядку.
- Размер игрока (20 на 20) закреплён в нескольких местах кода.
- Звука, спрites, меню и сохранения рекордов нет.
- Баланс (урон, перезарядки, частота появления врагов) подбирался на глаз и требует проверки в игре.
